# Results

This folder stores evaluation outputs generated from the notebook or training script.

Typical files:
- `metrics.json`
- `summary.csv`
- `training_history.csv`
- `accuracy_curve.png`
- `loss_curve.png`
- `confusion_matrix.png`
- exploratory PNG charts such as `outcome_distribution.png` and `feature_correlation_heatmap.png`
